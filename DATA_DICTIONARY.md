# Labeled scenario dataset data dictionary

## Dataset overview

`outputs/labeled_fault_scenarios.csv` contains hydraulic readings generated by the project's WNTR network model. It spans three watering profiles, normal operation, leaks and clogs, three injected severity levels, three fault locations, and six hourly steps.

- **Rows:** 342 scenario-hour records.
- **Scenario configurations:** 57 (3 normal schedule configurations plus 54 fault configurations).
- **Condition counts:** 18 normal, 162 leak, and 162 clog records.
- **Sensor features:** pressure and flow for each of Zones A, B, and C in each record.
- **Data provenance:** WNTR/EPANET simulation outputs using the assumptions documented in `first_simulation.py` and `fault_scenarios.py`.

Each `Scenario_ID` repeats for six consecutive hourly records from the same simulated configuration. Keep all rows sharing a `Scenario_ID` together when creating training and test sets to avoid splitting one simulated run across both sets.

## Fields

| Field | Type | Meaning | Unit or allowed values |
|---|---|---|---|
| `Scenario_ID` | Text | Identifier for one schedule, condition, severity, and fault-location configuration. | For example `LEAK_MORNING_MILD_ZONE_A`; repeated across hours 0–5. |
| `Schedule` | Category | Selected watering demand profile. | `morning`, `afternoon`, `night` |
| `Hour` | Integer | Hour within the six-hour simulated profile. | 0–5 |
| `Demand_Multiplier` | Number | Relative demand multiplier applied at the specified hour. | Dimensionless; profile values are defined in `first_simulation.py`. |
| `Condition` | Category | Injected operating condition. This is the target label for condition classification. | `normal`, `leak`, `clog` |
| `Severity` | Category | Injected fault severity. It is `none` for normal operation and is a scenario setting, not a model prediction. | `none`, `mild`, `moderate`, `severe` |
| `Fault_Location` | Category | Zone receiving the injected fault. It is `none` for normal operation. | `none`, `Zone A`, `Zone B`, `Zone C` |
| `Pressure_ZoneA_kPa` | Number | Simulated pressure reading in Zone A. | kPa |
| `Pressure_ZoneB_kPa` | Number | Simulated pressure reading in Zone B. | kPa |
| `Pressure_ZoneC_kPa` | Number | Simulated pressure reading in Zone C. | kPa |
| `Flow_ZoneA_L_min` | Number | Simulated branch flow for Zone A. | L/min |
| `Flow_ZoneB_L_min` | Number | Simulated branch flow for Zone B. | L/min |
| `Flow_ZoneC_L_min` | Number | Simulated branch flow for Zone C. | L/min |
| `Data_Source` | Text | Provenance label for the row. | `WNTR synthetic simulation` |

Fault parameters are simplified modeling choices: leaks use emitter coefficients and clogs reduce the affected zone's base demand. Model performance based on this dataset applies to these scenarios and assumptions.
